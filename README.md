# Yusr Clinic

A responsive web-based appointment booking system for a medical clinic, built with ASP.NET Web Forms and SQL Server.

## Features
- **Patient interface:** browse specialties and doctors, book an appointment, and receive an email summary.
- **Staff dashboard** (login required): manage doctors, specialties, patients, and appointments, and export appointments to Excel.

## Tech Stack
ASP.NET Web Forms (C#) · SQL Server · HTML/CSS

## Future Improvements
- Password hashing
- Role-based permissions for staff

## Note
Sensitive config files (`secrets.config`, `connections.config`) are excluded for security.
